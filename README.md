## The outcome

Start the day with priorities, schedule, overdue work, and recent context in one concise briefing. This skill covers priorities, tasks, calendar context, and recent meeting notes.

## What you get

A short operating brief that says what matters now, what is late, and what deserves attention before the inbox eats the morning.

## Quick start

1. Install the ClawHub skill: `ai-daily-briefing`
2. Run `/ai-daily-briefing`
3. Connect or provide the day’s schedule, task list, priorities, and recent context. Ask for the briefing at the start of the day.
4. Review the output before publishing, sending, or changing live systems.

## A useful first prompt

```text
Use /ai-daily-briefing with me. First ask only for the information you need to produce a reliable result. Do not invent missing facts, claims, prices, owners, or deadlines. Show me the draft before anything is published or sent.
```
